# Equals-attached short option values

Mamba supports `-o=file` and flag-prefix bundles such as `-vo=file`: all shorts before the last are flags, and the last short takes everything after the first `=` as its value. We chose explicit equals attachment rather than conventional no-equals attachment or mixed bundles with a separate value, keeping token ownership unambiguous across command resolution, parsing, control detection, and completion. A lone `-o file` and flag-only bundles remain valid; `-ofile`, `-vofile`, and `-vo file` remain unsupported, an empty attached value is supplied content subject to validation, and a flag-only bundle cannot take an attached value. A control-bearing bundle validates its entire token, including an attached value, before bypassing later ordinary tokens; help/version-looking text owned by an attached value is not a control request.
