# Mamba documentation

This Astro Starlight site contains Mamba’s guides and API reference.

## Setup

```sh
pnpm install
pnpm dev
```

## Create a documentation page

Run the generator from this `docs/` directory:

```sh
pnpm new-doc "Page title" "A short description of the page."
```

The command derives the content directory from the Astro configuration and asks
where to create the page. It offers the docs root, existing directories covered
by Starlight’s autogenerated sidebar, and the option to create a nested
directory under one of those sidebar sections. `guides` is selected by default
when available.

The optional third argument is a JSON object containing additional
[Starlight frontmatter](https://starlight.astro.build/reference/frontmatter/):

```sh
pnpm new-doc \
  "Command Hooks" \
  "Customize command execution with lifecycle hooks." \
  '{"sidebar":{"order":3},"draft":true}'
```

`title` and `description` must be passed as the first two arguments and cannot
be repeated in the JSON object. The generator validates all metadata against
the same Starlight schema used by Astro. Pass `lastUpdated` as an ISO-8601
string, for example `{"lastUpdated":"2026-09-03"}`.

### Options

- `--directory <path>` skips the prompt with a path relative to `src/content/docs/`.
- `--dry-run` prints the generated Markdown without writing it.
- `--help`, `-h` prints command help.

For example:

```sh
pnpm new-doc \
  "Options" \
  "Learn how Mamba command options accept and validate values." \
  '{"sidebar":{"order":2}}' \
  --directory reference \
  --dry-run
```

The filename is generated from the title in Unicode-aware kebab case. Existing
files are never overwritten.
