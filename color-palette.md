# Mamba color palette

The palette image has been converted into named tokens so the colors can be read, copied, and used without relying on the image. The correct title is **Mamba color palette**.

| Token | Hex value | Theme use |
| --- | --- | --- |
| Mamba Bright | `#B3CD58` | High-contrast accent in dark mode |
| Mamba Primary | `#92C362` | Primary accent and interactive controls |
| Mamba Mid | `#81AC4E` | Supporting green tone |
| Mamba Deep | `#50631E` | Dark-mode accent background and light-mode links |
| Mamba Black | `#11130A` | Dark-mode page background |

The Starlight theme maps these tokens to its accent and neutral color variables in `src/styles/mamba.css`.
